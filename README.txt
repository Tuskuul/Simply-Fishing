Simply Fishing v1.1.0 — WoW Forever (Interface 16001)

INSTALL
Extract the SimplyFishing folder into:
World of Warcraft\_forever_\Interface\AddOns\
Then /reload or restart the game.

SETTINGS
Esc -> Options -> AddOns -> Simply Fishing
Or use /sfish options or the Addon Compartment entry.

FEATURES
- One shared fishing/interact key
- Fishing cast with a pole equipped; normal Interact otherwise
- Fast Loot for fishing catches; optional global WoW Auto Loot toggle
- Settings page, key capture, and manual binding entry
- Keyboard keys and native controller button bindings with optional modifiers
- Left/right Alt, Ctrl, and Shift modifiers when supported by the client

MOUSE INPUT
Mouse buttons and mouse-wheel bindings are disabled in this release.
Saved mouse bindings from older test versions are cleared on startup.

COMMANDS
/sfish options          Open settings
/sfish bind F           Assign key
/sfish bind RCTRL-F     Right Ctrl + F
/sfish bind LSHIFT-G    Left Shift + G
/sfish bind SHIFT-PAD1  Gamepad button with modifier (client-dependent)
/sfish fastloot on/off  Toggle fast catch looting
/sfish autoloot on/off  Toggle WoW global Auto Loot
/sfish refresh          Refresh override binding
/sfish unbind           Remove assigned key
/sfish status           Show status
/sfish debug            Report binding diagnostics

NOTES
Gamepad button identifiers and modifier behavior depend on the WoW Forever
client and its native controller mappings. Manual entry is available if
capture does not receive a controller button. Fast Loot requires WoW Auto
Loot to be enabled. A fresh keypress is required to recast after looting.
Binding changes are restricted during combat.
